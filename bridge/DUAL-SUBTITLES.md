# 双字幕对照

0.2.0-preview.2 支持两路本地 SRT、两路内嵌文本轨道，以及内嵌与外部字幕混用。

播放视频后，选择「文件 → 双字幕对照…」或右键字幕菜单中的同名入口。为主、副字幕分别选择本地 SRT 文件或内嵌文本轨道，点击「应用」。默认主字幕在下方区域的上层，副字幕在下层；也可选择主字幕底部、副字幕顶部。

- 每路可以独立隐藏、调整字号和颜色，延迟使用毫秒。正数表示晚出现，负数表示早出现，范围为 ±600000 ms。
- 「交换主副」连同文件的延迟、颜色、字号和可见性一起交换。
- 原有字幕总开关控制两路；原有延迟快捷键、复制、保存及同步栏继续针对主字幕。
- 「关闭副字幕」回到普通主字幕。当前视频内可以重新开启副字幕；打开其他视频清空文件选择和延迟。
- 字号、颜色和布局保存到当前 INI。字幕文件、内嵌轨道及逐视频延迟不跨启动自动恢复。
- 两份字幕独立按时间显示，不要求条目数或分段一致。无需修改原文件或预先生成合并字幕。
- 同一视频切换清晰度或失败回退时，恢复两路文件及其参数。文件无法恢复时提示并回到可用的普通字幕。
- 启用字幕设置中的自动重载后，轮询两路文件变化；解析失败保留已加载内容，等待文件写完后重试。也可从普通字幕菜单手动重新加载。

双字幕需要内置字幕渲染器。两路来源可各自选择文件或播放器已连接的内嵌文本轨道。内嵌 UTF-8/SRT、ASS/SSA、WebVTT 通过原生文本解码链路读取；ASS/SSA 在双字幕中按文字显示，不保留定位与动画特效。原生单字幕不受影响。PGS、VobSub、DVB 等图片轨道不列入双字幕选择，仍使用普通单字幕。切入不支持的主字幕轨道会退出双字幕显示。

内嵌字幕随解复用器分批更新；双字幕监听两路的新增数据、跳转清空及轨道替换通知，在 UI 线程合并刷新。清晰度重建时按轨道名称和类型校验身份；轨道丢失或身份不明确时提示重新选择，避免静默切成其他来源。内嵌来源不参与文件自动重载，也不加入外部字幕播放列表。

过长文字会在分区内换行并缩小字号；达到最小字号仍无法放入时显示提示，请切换上下布局或减小字号。两路不会相互覆盖；不能把这个限制理解为所有长文本都一定可在小窗口中完整显示。内部字幕纹理支持到 UHD 4K 的面积预算，超出预算不纳入本版保证。

## 验证

自制黑底 MJPEG 视频及 UTF-8/UTF-16 字幕测试通过播放器自己的 JPEG 接口检查实际画面，覆盖两路同时出现、单路出现、空白间隙、独立延迟、两种布局、交换、总开关、无效文件保留、全屏和逐帧。测试只操作独立进程及临时 INI。

```bash
python tests/bridge/embedded_subtitle_playback.py 3
python tests/bridge/embedded_subtitle_playback.py 5
python tests/bridge/embedded_subtitle_playback.py 3 --ass
python tests/bridge/dual_subtitle_playback.py 3 --stress
python tests/bridge/dual_subtitle_playback.py 5
python tests/bridge/quality_cache_playback.py --dual
powershell -ExecutionPolicy Bypass -File tools/bridge/test.ps1 -Compiler C:/path/to/g++.exe
```

`3` 是 EVR Custom Presenter，`5` 是 MPC Video Renderer；`--stress` 额外执行 100 次替换并检查工作集增长。清晰度测试使用本机服务器及受控格式列表，检查切流、失败回退、暂停/倍速/音量和双字幕参数恢复，不依赖公网登录。

测试发现并修复了最小化时尚无 DX9 视频纹理却请求截图的空指针访问；画面测试恢复测试窗口后运行。MPC Video Renderer 下暂停加载或跳转需要同步字幕时间，并在队列更新后有限次重绘。

普通 SRT 功能已有受控回归；完整人工多显示器/DPI/HDR、全部字体/编码、复杂长文本和各类媒体兼容性仍未穷尽。独立模型检查、画面证据和压力结果不能代替这些测试。本版沿用项目的预览发布方式；清晰度与缓存的其他限制见 [缓存验证记录](CACHE-VALIDATION.md)。

本轮最终压力测试的 100 次替换后工作集增加 7102464 字节，约 6.8 MiB；这是单次受控运行的增量结果，不是完整 1080p/4K 性能矩阵。安装负载通过隔离 AppId 与快捷方式的安装/升级/卸载验证；正式身份的现有安装保留。

内嵌测试使用自制 MJPEG + 双文本轨道 MKV，包含 SeekHead、字幕 CueDuration 与 CueRelativePosition，以覆盖跳转到字幕区间中途时的重新投递。没有字幕索引的文件和第三方解复用器的恢复能力仍取决于其原生实现；仅暴露一个活动文本输出的解复用器无法同时提供两条内嵌轨道。未覆盖所有封装、直播或 DRM 媒体。
