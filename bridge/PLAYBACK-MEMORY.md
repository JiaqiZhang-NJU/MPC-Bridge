# 播放记忆

当前开发构建可以记住同一视频的观看位置、倍速、在线清晰度、音轨和字幕设置。关闭视频或退出播放器后，再次打开视频即可续播。

## 使用

- 从顶层或右键「播放记忆 → 播放记忆设置…」打开设置；「设置 → 播放器」中也有入口。
- 「保留历史记录」是总开关；「记住播放进度」和「记住每个视频的设置」可分别开关。关闭开关不会删除已保存的数据，重新打开视频时按当前开关决定是否恢复。
- 新配置默认开启记忆；已有配置中明确关闭的历史或进度开关继续保留。升级后若未自动续播，请先检查这里的开关。
- 「从头播放」把当前视频跳到零秒并更新进度，保留倍速和字幕设置。
- 「清除此视频的播放记录」删除进度和逐视频设置；设置窗口中可以清除全部记录。清除后，当前已打开的会话不再生成被清除的记录，重新打开视频后才开始重新记录。
- 音量、静音、窗口和全屏继续使用播放器的全局设置。重新打开时遵循原有的播放/暂停启动规则。

进度每五秒保存一次，暂停、正常跳转、关闭及退出会触发额外保存。强制结束进程可能损失最后一次成功保存之后的少量进度。按住方向键产生的临时 3 倍速不会变成下次打开的默认速度。

播放完成后，再次打开从头开始，倍速和字幕设置继续保留。停止按钮保留停止之前的位置。命令行明确指定的起点（包括零秒），以及支持链接中的 `t` / `start` 时间参数，优先于自动续播。

## 哪些视频可以记忆

普通本地文件以及现有入口支持、可以正常播放的 Bilibili / YouTube 点播视频。直播、无法定位的流和 DVD/蓝光特殊播放路径不增加新的续播规则。

YouTube 的 watch、youtu.be 和 shorts 链接可匹配同一视频，忽略分享、列表上下文和时间参数。视频 ID 保留大小写。Bilibili 不同分 P 和已解析的不同番剧单集分别记录；未能确认身份的入口采用保守处理。

本地文件按完整路径、大小和最后修改时间识别。同名但不同目录的文件分别记忆；同一路径替换内容后不会误用旧位置。移动、改名或修改文件后不保证继承原记录。

## 设置恢复与资源缺失

清晰度保存用户的选择意图，每次重新解析当前可用格式。旧格式不可用时，尝试相同高度、较低可用高度或当前默认选流规则；不会重用上次的临时签名媒体地址。选择「按默认设置」可取消本视频的固定清晰度偏好。

双字幕保存两路文件或内嵌文本轨道的身份、显示开关、延迟、字号、颜色、布局和总开关。文件丢失或某路轨道无法确认时，尝试显示仍可用的一路并保留原配置；文件重新可用后，再次打开可恢复原配置。图片字幕和外部字幕渲染器仍沿用原生能力，不承诺完整逐视频恢复。

内嵌音轨和字幕按可验证的描述匹配；有歧义时不会只凭上次的列表下标选择另一语言。多实例播放不同视频时合并各自的记录；同一视频由较晚打开的会话拥有写入权，较早会话随后退出不会覆盖新会话。

## 数据与恢复

记录位于当前播放器配置目录中的 `playback-memory.json`，保留一个 `.bak` 备份。默认最多 200 条，沿用播放器的历史数量上限；清理音视频缓存不会清除此文件。安装版、便携版升级时应保留用户文件，发布包不包含个人记录。

写入在后台完成，通过目录锁协调多个进程，先完整写入临时文件再替换。主文件损坏时尝试读取备份；未知的更新版本格式不会被当前程序覆盖。删除记录时同时更新备份，防止旧备份恢复已删除的记录。

路径或磁盘故障会提示记录暂时无法保存，不阻塞正常播放。配置保存位置发生变更时迁移并合并记录。旧原生网页历史只对完全相同的链接尝试导入一次；旧历史没有本地文件校验信息，因此不自动导入旧的本地文件位置。
